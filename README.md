# Sales Analytics with SQL & Python | Análisis de Ventas con SQL y Python

## English

### What it does
This project turns raw sales data into trustworthy business insights. It cleans and explores data with Python and Pandas, then uses SQL to answer questions about revenue, profit, customers, products, and regions.

### How it works
The workflow is: raw data -> quality checks and cleaning -> SQL analysis -> visualizations -> business recommendations. Every insight is documented so another analyst can reproduce it.

### Why it matters for future applications
This is the analytical foundation for more advanced systems: automated reporting, scheduled ETL pipelines, customer segmentation, forecasting, and data-driven decision tools.

## Español

### Qué hace
Este proyecto convierte datos crudos de ventas en hallazgos confiables para el negocio. Limpia y explora datos con Python y Pandas, y utiliza SQL para responder preguntas de ingresos, utilidad, clientes, productos y regiones.

### Cómo funciona
El flujo es: datos crudos -> validación y limpieza -> análisis SQL -> visualizaciones -> recomendaciones de negocio. Cada hallazgo queda documentado para poder reproducirse.

### Para qué sirve en aplicaciones futuras
Es la base analítica de sistemas más avanzados: reportes automáticos, pipelines ETL programados, segmentación de clientes, pronósticos y herramientas de decisión basadas en datos.

## Stack

Python, Pandas, SQLite, SQL, Matplotlib, Seaborn, Jupyter.
